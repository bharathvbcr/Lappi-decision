## The loader layout, as found (verified, by reading)

The serving loader is qd-metal. `qd` itself wires no model backend (`crates/qd-runtime/src/main.rs:47-49`);
qd-metal is reached through `MetalBackend` (`crates/qd-metal/src/backend.rs:149-170`) from its
bins and tests. What it opens, all relative to one snapshot directory:

| What | Where it is read | What it requires |
| --- | --- | --- |
| `config.json` | `config.rs:87-92` | conditional-generation config with `text_config` (or a text config); `tie_word_embeddings` read top-level first, then `text_config` (`config.rs:154-161`); kernel limits: `head_dim` 256, `linear_key_head_dim` 128, GDN/rope rules (`config.rs:134-226`) |
| weights | `model.rs:870-901` | `model.safetensors.index.json` naming exactly one file for the text tower, else `model.safetensors` |
| tensor names | `weights.rs:26`, `:199-260` | exactly the 320 `model.language_model.*` tensors the forward pass reads; other prefixes are ignored silently (`:247-251`) |
| dtypes | `model.rs:329`, `weights.rs:85-93` | `embed_tokens` and every linear weight **BF16**; norms, `conv1d`, `A_log`, `dt_bias` any of BF16/F16/F32 |
| shapes | `weights.rs:143-186`, `model.rs:328-341` | from the config: GDN conv dim `2*k_heads*128 + v_heads*v_dim`, `q_proj` `2*q_heads*head_dim` (output gate) |
| vocabulary | `config.rs:106`, `model.rs:329` | `embed_tokens` `[vocab_size, hidden]` = `[248320, 2048]` for the 2B |
| tokenizer | `backend.rs:331`, `tokenizer.rs:28-56` | `<dir>/tokenizer.json`; its sha256 is the identity's `tokenizer_hash`; the 17 letters A–P, Z each one token |
| span head | — | **not read anywhere**: no `span_head` in qd-metal, `pooled_features` is Unavailable (`backend.rs:278-287`), a `PointerStart` decode is refused (`tests/gpu.rs:174-176`) |
| calibration | `backend.rs:63-65`, `runtime.rs:115-133` | the backend is *given* a `calibration_hash`; the runtime holds a `CalibrationTable`. There is no calibration file loader (`calibration.rs:140` says one is meant to exist) |
| manifest / hash binding | `runtime.rs:188-215` | the loader checks **no** manifest. It *reports* `weight_hash` (`weights.rs:262-272`), `tokenizer_hash`, `head_hash`, `label_set_hash`, `calibration_hash` (`backend.rs:345-366`); a caller pins any of them through `HashExpectation` and `check_hashes` refuses a mismatch |

So the target is an HF-snapshot-shaped directory (the base snapshot's text half), not a
generic HF export: the loader wants the conditional-generation `config.json` and the
`model.language_model.` prefix.

### Decisions made (state them so they can be overruled)

- **Every tower tensor is BF16**, including `A_log`, norms, `conv1d` and `dt_bias`, which the
  loader would also accept as F32. The base snapshot stores 36 text tensors as F32 (the 18 GDN
  `A_log` and 18 `linear_attn.norm.weight`, verified from its header); a bf16 training tower
  already holds them bf16 (`backbone.py:503` casts every tensor), so for a bf16 average the
  cast is the identity. For an fp32-masters average (`ckpt_average --from masters`, the
  parallel lane) those 36 lose the precision the masters had: that is the cost the decision
  accepts, and the box check reports it as `release_vs_tower`. F32 → BF16 is round to nearest,
  ties to even; F16 widens exactly then rounds once; BF16 is copied bit for bit.
- **The span head stays F32**, untouched: it is float32 on purpose (`backbone.py:825-833`) and
  nothing serves it yet (`GAP-J7-EXPORT-SPAN-HEAD-UNSERVED`).
- **Kernel-only config limits are not re-checked** by the exporter (head_dim 256 etc.); the
  config is the base snapshot's byte for byte, and the round-trip test runs qd-metal's own
  `ModelConfig` over the release. Layout-relevant fields are checked: sizes, `layer_types`,
  `tie_word_embeddings`, `attention_bias`, `attn_output_gate`, `mlp_only_layers`.
- **An empty `ft_row_ids` is refused**: a release names the ledger rows it came from.

## Refusals, each with its test (verified: `cargo test -p qd-export`, 25 passed)

| Refusal | Test |
| --- | --- |
| existing output dir (also the staging dir) | `refusals.rs::an_existing_output_directory_is_never_written_into`; `roundtrip.rs` re-export |
| tower dtype not BF16/F16/F32 (F64, I32); span head not F32 | `a_dtype_that_is_not_a_trained_float_is_refused` |
| NaN / Inf, or a finite value rounding to Inf (f32::MAX) | `a_value_that_is_not_a_finite_bf16_is_refused_and_staging_is_cleaned_up` |
| missing tensor (tower or span head), all named | `a_tensor_the_loader_needs_must_be_there` |
| extra tensor without `--allow-extra NAME=REASON`; stale or duplicate allowlist entry; allowed extras dropped and recorded | `an_extra_tensor_is_refused_unless_dropped_with_a_reason` |
| shape not implied by the config | `a_shape_the_config_does_not_imply_is_refused` |
| vocabulary: `--expect-vocab-size` vs config vs source manifest vs embedding rows (a remapped tower) | `the_vocabulary_must_agree_everywhere` |
| source manifest: sha256 not the file's, `n_tensors`, empty `ft_row_ids`, missing field, missing file | `the_source_manifest_must_describe_the_source` |
| tokenizer: pin mismatch, malformed pin, missing file | `the_tokenizer_must_be_the_pinned_one_and_complete` |
| calibration: invalid entry, a field the runtime drops, not a `CalibrationTable` (and `1` == `1.0` accepted) | `the_calibration_table_must_be_one_the_runtime_reads_back_unchanged` |
| config layout the loader does not read | `a_config_whose_layout_the_loader_does_not_read_is_refused`; `layout.rs` unit tests |

Every refusal test also asserts no release and no staging directory is left behind.

## Verification

**(a) Round trip through the loader's own code (verified, CPU only).**
`crates/qd-export/tests/roundtrip.rs::the_release_loads_through_qd_metal_and_holds_the_bf16_cast_of_every_tensor`
on a tiny qd-metal-valid tower (head_dim 256, GDN key 128, mixed BF16/F16/F32 source with exact
rounding ties): qd-metal's `ModelConfig::load`, `weights_file`, `SafeTensors::open`,
`check_text_tensor_set`, then `prepare_layer` for every layer and the embed/norm digests —
`Model::load`'s CPU half — reproduce the manifest's `weight_hash`; every tensor equals tessl's
`f32_to_bf16_bits` of the source; both readers agree on every header entry; `QwenTokenizer`
loads the release's tokenizer and its hash is the manifest's. Plus: the bf16 cast equals
tessl's on 393,231 f32 bit patterns (all 65,536 upper halves with low halves 0x0000, 0x7FFF,
0x8000, 0x8001, 0xFFFF, plus a 65,521-stride sweep), refusing exactly where tessl's result is
not finite; F16 widening equals tessl's on all 65,536 halves; the layout for the real 2B
config is qd-metal's 320 names exactly.

**Real 2B, real size (verified, CPU only, 68 s):**
`snapshot_the_base_weights_export_at_248320_and_load_through_qd_metal` (`#[ignore]`d; run with
`cargo test --release -p qd-export --test roundtrip -- --ignored`). The Qwen3.5-2B-Base
snapshot's own 320 text tensors, renamed `tower.*` beside a zero span head, exported with
`--expect-vocab-size 248320` and the real tokenizer pin: `model.safetensors` is 3,763,692,048
bytes; qd-metal's `ModelConfig` (vocab 248,320), `check_text_tensor_set` and `prepare_layer`
over all 24 layers accept it; the 284 tensors that are BF16 in the base come back
bit-identical; the 36 that are F32 in the base (18 `A_log`, 18 `linear_attn.norm.weight`,
read from its header) come back as tessl's bf16 cast; the loader-path weight hash equals the
manifest's; `QwenTokenizer` loads the copied `tokenizer.json` with hash `fe000e3e…`. This is
the base weights, not a trained average; its weight hash identifies nothing that will ship.

**(b) Python oracle (verified, CPU).** `python/tests/test_export_oracle.py`, 3 passed: real
checkpoints of a tiny tower → `tools/ckpt_average.py` → the Rust binary → transformers 5.12.1.
Weights: every tensor equals torch's own `.to(torch.bfloat16)` of the tower, bit for bit
(this checks the Rust RNE against torch's on every fp32 weight). Letter logits: release vs
bf16-cast tower **0.0** max |diff| for both a bf16 and an fp32 tower (6 rows); release vs the
uncast fp32 tower **6.6e-4** max |diff| with logits up to 0.59 (bound in the test: 1e-2, for
that fixture only); a flipped bit fails both gates. The tiny config needed two fields the real
config already states (`tie_word_embeddings` top-level true, `attn_output_gate` true —
transformers always builds the gated `q_proj`, `modeling_qwen3_5.py:658`); neither changes a
tensor.
