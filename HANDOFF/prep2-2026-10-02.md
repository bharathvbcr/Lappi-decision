## Part A: the strip

**The one function.** `python/qd_train/containment_strip.py` holds `strip_template`. Per
(family, slot), over the union of every set's rendered rows at `seed=None` (sources and
targets alike), it removes two things before n-gramming:

- a question line that is byte-identical in every row;
- each option value that is present in every row.

**Where it applies.** Two call sites use the same function:

- `tools/containment_scan.scan_sets`, before the request is written;
- the parity test's oracle, before `decontaminate`.

`qd_train.replay.prompt_content` is unchanged, because J6(a)'s replay decontamination reads
it.

**The cut is guarded.** `slot_parts` cuts a prompt where `prompt_content` cuts, and refuses if
the unstripped join differs. So `--no-template-strip`, which is for measurement only, writes
byte for byte the pre-strip export [V, `test_apply_false_is_byte_for_byte_the_pre_strip_export`].

**What attestation v2 records.** `export.template_strip` holds the record. It is written on the
tool side; no Rust changed.

- Top level: `applied`, `rule`, `version`, `n`, `min_rows_for_constant`,
  `groups_below_min_rows`.
- Per family-slot: `rows` and `stripped` (the question and options).
- Per family-slot: `n_stripped` and `stripped_sha256`, the sha256 of
  `json.dumps({"question", "options"}, sort_keys=True, ensure_ascii=False)`.
- Per family-slot: `too_short_before_strip`, `too_short_after_strip`, and `by_set`, which
  holds both counts per set.
- Per family-slot: `option_sets`, with `distinct` and `largest_share_rows`.

**The hook refuses unstripped lists.** `qd_train.exclusions.read_exclusions` refuses a list
whose attestation did not apply the strip. It checks that `applied` is true and that `rule` and
`version` are this module's.

### How the rule's text was read (GAP-CONTAINMENT-STRIP-RULE-PREMISES-2026-10-02)

The amendment should state these four points.

1. **The question line is constant in every family.** `qd_data.mixture._request`
   (`mixture.py:238-264`) renders `family.description` as every row's question line [V].
   - So the rule strips it in MMLU, CSQA, SQuAD and defect_class too.
   - Their per-row question is in the CONTEXT block. For MMLU and CSQA,
     `general.py` sets `context=question`. For SQuAD, the context is the question, a blank line,
     then the passage.
   - The strip never touches the context, so those questions are kept whole, as the DRAFT
     intends. The DRAFT's parenthetical ("questions vary per row") describes the context, not
     the question line.
2. **The per-domain option lists are intent.within_domain's**, built by
   `rewrite_clinc_two_stage` (`general.py:397-460`) [V].
   - intent.classification is different: it samples 15 random distractors plus the gold,
     sorted, per row (`mixture.py:480-510`).
   - Fable's caveat names the wrong family.
3. **One-row groups strip nothing.** "Byte-identical across every rendered row" is vacuous for
   a single row. A (family, slot) group of fewer than 2 rows therefore strips nothing, and the
   attestation names it. No group was that small in the 1/2/5% scans [V].
4. **Constancy means membership.** An option value is constant when every row's option values
   contain it, at `seed=None`. For the fixed lists measured, the positional reading gives the
   same set [V].
