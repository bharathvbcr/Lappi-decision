## 2. Format: context first (human item 8)

The minimal reading of the human's decision is that the question moves and nothing else
does. Task and route stay ahead of the context, so N questions with one task over one diff
share every byte through `<|qd_context_end|>`.

```
v4: <|qd_begin|> <|qd_schema_version|>1 <|qd_task|>T <|qd_route|>R <|qd_question|>Q <|qd_context_begin|> C <|qd_context_end|> | slots
v5: <|qd_begin|> <|qd_prompt_format|>2 <|qd_schema_version|>1 <|qd_task|>T <|qd_route|>R <|qd_context_begin|> C <|qd_context_end|> <|qd_question|>Q | slots
```

- **Seeds 3-4:** run iff the three 8K worst buckets on the rebuilt suite spread by more than

- **The noul-weight arm ×3** (human item 6) runs after J5′, with `--noul-weight 4`.
  - **The flag:** it multiplies the cross-entropy at supervised letter positions whose target
    is Z, in every family. The loss stays a mean over supervised positions, so every other
    row's pull is unchanged. The span abstain row is not weighted. The code goes in
    `python/qd_train/fused_ce.py` and `backbone.py:_letter_loss`.
  - **Why w = 4:** 6,010 prose-noul rows compete with 22,624 MMLU/CSQA letter rows, so parity
    needs w ≥ 3.76. 4 is the smallest value in Fable's 3-5 range that reaches parity (24,040);
    3 stays below it (18,030).
  - **Targets:** `ood_abstain.prose` and `ood_abstain.unseen-language`, read as **seed_holds**.
    A seed holds iff its count is at least 30/60, the F2 bar of
    `campaign/v4-noul-v3b-preregistered.json`.
  - **A target clears** iff all three arm seeds hold **and** the arm holds on strictly more
    seeds than v5's envelope does. If v5 already holds on 3 of 3, that target has no room
    and becomes a guard. If neither target has room, the arm does not launch without a new
    human yes.
