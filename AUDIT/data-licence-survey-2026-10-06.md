# Data licence and contamination survey for the next Lappi data build (2026-10-06)

**Status: evidence, not a decision.** A research agent (`docs-researcher`) gathered this; this
session saved it. Nothing has been downloaded. Every fetch waits for the human's approval of one
consolidated list.

**How to read the labels**
- **[fetched]**: the agent opened the primary page (HF card or API, GitHub or GitHub API, Zenodo,
  arXiv, or the official site). Fetches go through a summarising model, so treat quoted text as
  the tool's quote and re-check it against the raw card before it gates anything.
- **[snippet]**: search-result text only.
- **Licence unclear**: the card is silent, contradicts itself, or relicenses upstream data it
  cannot relicense. An unclear licence is **refused**, the same as Nimble (`qd_data.licences`).
- **Provider-output terms flag**: the licence is permissive, but the outputs came from GPT,
  Claude or Llama models, whose terms may restrict use.

**Gaps with no clean source:**
- a general web passage-reranking set (MS MARCO and its derivatives are non-commercial);
- a labelled real-email spam/phishing/triage corpus (every real-email option has an unclear
  licence or carries personal data);
- a text accessibility-tree element-selection set (Mind2Web is research-only, carries "never in
  training corpora" canaries, and its test splits are evals; WebLINX and GUIrilla are
  non-commercial).

These need synthetic data generated by rule, or the human's own data with consent.

## Do not train on

**Evals:**
- BFCL (all versions)
- When2Call test_mcq and test_llm_judge
- BEIR: SciDocs, TREC-COVID, NFCorpus
- SciRepEval eval-only configs and `allenai/scirepeval_test`
- SciRerankBench
- MS MARCO dev
- CodeSearchNet test
- CoSQA WebQueryTest
- LocBench and SWE-bench(-Lite)
- Mind2Web test splits
- RM-Bench and RewardBench
- MNLI validation_matched / validation_mismatched
- ANLI dev/test
- Defects4J, BugsInPy, GitBug-Java
- FormFactory

**Licence (non-commercial, research-only, unclear, or inherited from a non-commercial
upstream):**

  conflicts with research-only text)
- `Salesforce/APIGen-MT-5k` (CC-BY-NC, plus OpenAI terms)
- `mangopy/ToolRet-Training-20w` (no licence)
- MS MARCO (non-commercial research only), `unicamp-dl/mmarco`, `Shitao/bge-m3-data`
